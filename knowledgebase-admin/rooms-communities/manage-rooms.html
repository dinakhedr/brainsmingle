Manage rooms

Last updated: July 2026

View all rooms on your platform, search and filter by status or type, edit event details, manage sponsorship and ad placements, and review event members and attendees.

Open the Rooms page

  1. Open the Admin Panel.
  2. Click Rooms in the left sidebar.

The Rooms Management page displays a table of all rooms with a total room count in the top-right corner. Each row shows the room owner's ID, avatar, name, username, contact email, plan, timezone, hosting status, join date, and action buttons.

Search and filter rooms

  1. To find a specific room, type a title, description, or public ID into the search bar at the top of the page.
  2. To filter by status, click the All Status dropdown and select one:
    • All Status — shows every room regardless of status.
    • Live Now — shows only rooms that are currently in session.
    • Upcoming — shows only rooms scheduled for the future.
    • Past — shows only rooms that have already ended.
  3. To filter by type, click the All Types dropdown and select one:
    • All Types — shows every room type.
    • Networking — shows only networking rooms.
    • Webinar — shows only webinar rooms.
    • Video Call — shows only video call rooms.
  4. Click Search to apply the filters.

Edit a room

  1. Click the pencil icon in the room's Actions column.
  2. In the Edit Event dialog, update any of the following fields:
    • Title — the event name displayed to participants.
    • Description — a summary of the event topic or agenda.
    • Date & Time — the scheduled start date and time.
    • Timezone — the timezone for the event (e.g. Africa/Cairo).
    • Duration (minutes) — the planned length of the event in minutes.
  3. Under Event Settings, toggle Discoverable (Public) to control whether the event appears in public discovery.
  4. Click Save Changes to apply, or Cancel to discard.

Manage sponsorship

Click the handshake icon in the room's Actions column to open the Sponsorship dialog. The dialog has two tabs: Sponsor Data and Placements.

Sponsor Data tab

The Sponsor Data tab shows two sections:

  • Reusable Sponsor Data — lists sponsors previously saved for other events. Once a sponsor is saved for one event, it becomes available here for reuse across events.
  • This Event Sponsors — lists sponsors currently assigned to this event, with a count of sponsor records and a + New Sponsor button.

Add a new sponsor

  1. Click + New Sponsor in the This Event Sponsors section.
  2. Fill in the sponsor details:
    • Sponsor Title — the sponsor's display name.
    • Sponsor Type — select a tier from the dropdown (e.g. Gold, Silver, Bronze).
    • Description — a short description of the sponsor.
    • Sponsor Logo — a URL to the sponsor's logo image, or upload one.
    • Sponsor Card Image — a URL to the sponsor's card image, or upload one.
    • Sponsor Link — the URL visitors are directed to when they click the sponsor.
    • Button Title — the label on the sponsor's call-to-action button (e.g. "Learn More", "Visit IBM").
    • Card can be shown — check this box to make the sponsor card visible.
    • Display Order — a number that controls the order sponsors appear (lower numbers appear first).
  3. Click Save Sponsor to create the record, or Cancel to discard.

After saving, the sponsor appears in the This Event Sponsors section with its logo, name, tier, status, and a Choose button. Click the delete icon to remove a sponsor.

You can add multiple sponsors to a single event. Each sponsor card shows its logo, name, tier, and status.

Placements tab

The Placements tab controls where sponsor cards appear on the platform. You must create at least one sponsor before placements become available.

Once sponsors are added, the Placements tab displays two sections — Event Details Page and Associated Rooms — each listing every sponsor with toggleable placement types:

Placement type Description
Logo Bar Displays the sponsor logo in a horizontal bar.
Skyscraper A tall vertical ad placement alongside content.
Inline Compact A small inline placement within the content area.
Header Logo Displays the sponsor logo in the page header.
Floating Notification A floating notification card that appears on screen.
Native Card A sponsor card styled to match the platform's native layout.
Banner Hero A large banner placement in the hero section.
Sidebar Tile A tile placement in the sidebar area.
Message Strip A horizontal message strip placement.

Click any placement type to toggle it on (highlighted in purple) or off for each sponsor in each section independently.

View event members

  1. Click the group-of-people icon in the room's Actions column.
  2. The Event Members dialog displays summary counts at the top:
    • Total — the total number of members.
    • Approved — the number of approved members (highlighted in green).
    • Waitlisted — the number of waitlisted members.
  3. Use the tab bar to filter the list by All, Approved, or Waitlisted.
  4. Each member row shows the user's avatar, name, approval status badge, email, and user ID.
  5. Click Close to dismiss the dialog.

View event attendees

  1. Click the person-with-checkmark icon in the room's Actions column.
  2. The Event Attendees dialog displays the actual attendee count in the header and lists each person who joined the session. Each attendee row shows:
    • The attendee's avatar, name, and email.
    • Joined — the date and time the attendee entered the room.
    • Left — the date and time the attendee exited the room.
    • Duration — the total time spent in the room.
  3. Click Close to dismiss the dialog.
