Manage users

Last updated: July 2026

View all registered users on your platform, search and filter by status, edit user details, change plans, and review each user's hosted events and consultation services.

Open the Users page

  1. Open the Admin Panel.
  2. Click Users in the left sidebar.

The Users Management page displays a table of all registered users with a total user count in the top-right corner. Each row shows the user's ID, avatar, name, username, headline, contact email, plan, timezone, status, join date, and action buttons.

Search and filter users

  1. To find a specific user, type a name, email, or username into the search bar at the top of the page.
  2. To filter by hosting status, click the All Users dropdown and select one:
    • All Users — shows every registered user.
    • Can Host — shows only users who have hosting privileges.
    • Cannot Host — shows only users without hosting privileges.
  3. Click Search to apply the filter.

Understand the user table

Each row in the user table displays the following information:

Column Description
ID The unique user ID assigned at registration.
Avatar The user's profile photo or a colored initial placeholder.
User Info The user's display name, @username, and headline (if set).
Contact The user's registered email address.
Plan The user's current plan: Free, Basic, Pro, or Enterprise.
Timezone The user's timezone setting (e.g. Africa/Cairo, America/Toronto), or N/A if not set.
Status Can Host (green) means the user can create and host rooms. Can't Host (grey) means hosting is disabled.
Joined The date the user registered on the platform.
Actions Three action buttons: Edit User, View Hosted Events, and View Consultation Services.

User actions

Each user row has three action buttons in the Actions column:

Edit a user

  1. Click the pencil icon in the user's Actions column.
  2. In the Edit User dialog, update any of the following fields:
    • First Name — required.
    • Last Name — required.
    • Notification Email — required. The email used for platform notifications.
    • Username — required. The user's unique @handle.
    • Plan — select from the dropdown. Premium plans (Plus, Pro, Community) have additional features.
  3. Click Save Changes to apply, or Cancel to discard.

View hosted events

  1. Click the calendar icon in the user's Actions column.
  2. The Hosted Events dialog displays all rooms the user has hosted. Each event card shows:
    • The event title and type (e.g. Networking).
    • The event description.
    • Date, time, and duration.
    • Number of attendees and maximum capacity.
    • Timezone.
  3. Click the external link icon on any event card to open it in a new tab.

View consultation services

  1. Click the speech bubble icon in the user's Actions column.
  2. The Consultation Services dialog displays all consultation services the user has created. Each service card shows:
    • The service title and status (Active or Inactive).
    • Visibility (Public or Private).
    • The service description.
    • Hourly rate in USD.
    • Session duration.
    • Creation date.
  3. Click the external link icon on any service card to open it in a new tab.
