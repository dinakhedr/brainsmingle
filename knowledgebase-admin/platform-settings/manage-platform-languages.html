Manage platform languages

Last updated: July 2026

Choose which languages your platform supports and set a default language. Members can switch between supported languages using the language picker.

Open the Languages page

  1. Open the Admin Panel.
  2. Click Languages in the left sidebar.

The Languages page displays a table of all available languages. Each row shows the language name, its native name, and a language code badge (e.g. en, ar, tr).

Enable or disable languages

  1. In the Supported column, check the box next to each language you want to make available on the platform.
  2. Uncheck a language to remove it from the language picker. Users will no longer be able to select it.
  3. Click Save to apply the changes.

The available languages are English (en), Arabic العربية (ar), Urdu اردو (ur), Turkish Türkçe (tr), Spanish Español (es), and French Français (fr).

Set the default language

  1. In the Default column, select the radio button next to the language you want as the default.
  2. Click Save to apply.

The default language is shown to new visitors whose browser language is not in your supported list. Only one language can be set as the default at a time.
