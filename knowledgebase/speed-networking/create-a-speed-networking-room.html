Create a Speed Networking Room

Last updated: July 2026

Speed networking rooms automatically match participants into timed 1:1 video calls. Set the room duration, call length, role‑based matching, scheduling, and access controls — the platform handles the rest with no repeats and no manual coordination.

Before you get started

  • You must have an Admin or Moderator role to create speed networking rooms.
  • If you want to use role‑based matching, this feature requires an upgraded plan.
  • Intro room and outro room (group calls before and after matching) also require an upgraded plan.

Set the room purpose and identity

  1. Click + Create Room in the top navigation bar.
  2. Select Speed‑Networking Room.
  1. Under Room Purpose & Identity, enter a Room title.
  2. Enter a Room description that tells participants what to expect and suggests discussion topics.
Please note: Role‑based matching requires an upgraded plan. If roles are not enabled, the platform defaults to random matching with no repeats.
  1. To enable role‑based matching, toggle Enable role‑based matching on. Under Role Configuration, enter a Role 1 name and Role 2 name (e.g., Investor and Founder). Select a Matching Mode: Opposite (Role 1 meets Role 2) or Same (Role 1 meets Role 1). If role‑based matching is disabled, matches are random.
  2. Click Continue →.

Configure the experience design

  1. Under Experience Design, optionally toggle Intro room on to add a 5‑minute group call at the start of the room before matching begins.
  2. Optionally toggle Outro call on to add a 5‑minute group call at the end directly before the room finishes.
  3. Set the Total Room Duration using the slider or the +/- controls. The range is 20 to 60 minutes. Durations above 60 minutes require an upgraded plan.
  4. Set the 1:1 Call Duration using the slider or the +/- controls. The range is 3 to 15 minutes per call.
  5. Click Continue →.
Tip: The platform calculates the maximum number of conversations automatically. For example, a 30‑minute room with 5‑minute calls gives participants up to 6 conversations.

Set the schedule

  1. Under Scheduling, select a Date & Time. The time is set in your local timezone.
  2. Select your Timezone from the dropdown. Participants see event times converted to their local timezone.
  3. To set up a repeating event, toggle Recurring Room on. Select a repeat frequency (e.g., Weekly) and optionally set an End Date.
  4. Click Continue →.
  1. If you toggle Recurring Room on, select a repeat frequency from the Repeats dropdown and optionally set an End Date. A confirmation message shows the repeat schedule.
  1. Select a repeat frequency from the Repeats dropdown:
    • Daily — repeats every day.
    • Weekly — repeats on the same day each week.
    • Bi‑Weekly — repeats every two weeks.
    • Monthly — repeats on the same date each month.
    • Custom Days — lets you pick specific days of the week.
  1. If you select Custom Days, use the Repeat on day picker to choose specific days of the week. The confirmation message updates to show which days your room will repeat on.

Configure access and privacy settings

  1. Under Access & Privacy Settings, optionally add Tags to categorize your room and help people find it.
  2. Optionally select a Spoken Language for the room.
  3. Under Access & Visibility Settings, configure:
    • Room Privacy — toggle between Approval Required and Auto‑Approve. Auto‑approve lets anyone with the link join without requiring your approval.
    • Discoverability — toggle between Unlisted (direct link only) and Discoverable (visible in search and listings).
    • Add to Community — if you manage a community, you can link this room to it so community members can find and join. Select your community from the list, or choose Don't add to a space to keep the room standalone and accessible only via direct link.
    • Paid Event — toggle between Free and Paid. If paid, set the ticket price.

Set up paid access (optional)

Toggle Paid Event to Paid to charge participants. Enter the Price (USD) for your room. BrainsMingle charges a 10% platform fee, and the net amount you receive per attendee is displayed below the price field.

The Discount codes section shows any codes that automatically apply to this room. If no codes exist yet, you can click Create a discount code to set one up on the Coupons page. When a code is active, it appears with its discount percentage and an Always applies badge.

Please note: BrainsMingle charges a 10% platform fee on paid sessions. The net amount you receive per attendee is displayed below the price field.

Set up a registration form (optional)

  1. To require attendees to fill a registration form before joining, toggle Require attendees to fill a form on.
    • Enter a Form title (e.g., "Registration for our session").
    • Under Quick Add from Suggestions, click + next to any suggested fields to add them (Full Name, Email Address, Phone Number, Company / Organization, Job Title, LinkedIn Profile URL, What brings you here?, How did you hear about us?).
    • To add a custom question, click + Add question and enter your question text.
Please note: You must add at least one question with text to enable publishing.

Review and create

After completing all steps, a Room Summary & Preview card appears showing your room title, date and time, duration per call and total duration, and visibility settings. Review the details, then click Create Room to publish your speed networking session.
