Set up a recurring speed networking room

Last updated: July 2026

Schedule a speed networking room that repeats automatically on a regular basis. Set the frequency and optional end date during room creation — the platform creates each occurrence for you.

Before you get started

  • You must have an Admin or Moderator role.
  • You need to start creating a speed networking room first. See Create a speed networking room.

Enable recurring room

  1. During room creation, navigate to the Scheduling step.
  2. Set your Date & Time and Timezone.
  3. Toggle Recurring Room on.
  4. Select a repeat frequency from the dropdown (e.g., Weekly).
  5. Optionally set an End Date to stop the recurrence after a specific date. If no end date is set, the room repeats indefinitely.
  1. Select a repeat frequency from the Repeats dropdown:
    • Daily — repeats every day.
    • Weekly — repeats on the same day each week.
    • Bi‑Weekly — repeats every two weeks.
    • Monthly — repeats on the same date each month.
    • Custom Days — lets you pick specific days of the week.
  1. If you select Custom Days, use the Repeat on day picker to choose specific days of the week. The confirmation message updates to show which days your room will repeat on.
Tip: Recurring speed networking rooms work well for weekly or monthly community mixers. Each occurrence uses the same settings — title, duration, call length, and access rules — so you only configure once.
