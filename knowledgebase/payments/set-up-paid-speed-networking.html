Set up paid speed networking

Last updated: August 2026

Charge participants to join your speed networking rooms. Set a ticket price, review the platform fee breakdown, and optionally attach discount codes to offer promotions.

Before you get started

  • You must have a connected payment account to receive payouts. See Connect Stripe and receive payouts.
  • You need an existing speed networking room or be in the process of creating one. See Create a speed networking room.

Enable paid access

  1. While creating or editing a speed networking room, navigate to the Access & Privacy Settings step.
  2. Under Access & Visibility Settings, find the Paid Event toggle.
  3. Toggle from Free to Paid.
  4. Enter the Price (USD) for your room.

BrainsMingle charges a 10% platform fee on paid rooms. The net amount you receive per attendee is displayed below the price field.

Please note: BrainsMingle charges a 10% platform fee on paid rooms. For example, if you set a price of $120, you receive $108 per attendee.

Attach discount codes (optional)

The Discount codes section appears below the price field when paid access is enabled. It shows any codes that automatically apply to this room.

If no codes exist yet, you can click Create a discount code to set one up on the Coupons page. When a code is active, it appears with its discount percentage and an Always applies badge.

Tip: To create or manage discount codes, see Create and manage coupons.
