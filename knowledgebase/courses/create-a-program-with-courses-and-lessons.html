Create a program with courses and lessons

Last updated: July 2026

Build a structured learning experience by creating a program, adding courses to it, and filling each course with video or text lessons. Programs group related courses under a single title so members can enroll once and access everything in one place.

Before you get started

  • You must be a community admin or Suite Admin.
  • Your community must have the Courses tab visible. See Set up your community to enable it.

Open the Courses tab

  1. Open your community.
  2. Click Courses in the left sidebar.

The Courses tab shows all programs and standalone courses. From here you can create a new program, add a course, manage certificates, or view analytics.

Create a program

  1. Click New program.
  2. Enter a Title for the program.
  3. Optionally add a Description.
  4. Under Cover image, click Add a cover image to upload an image.
  5. Under Visibility, select one:
    • Draft — only admins can see it.
    • Published — visible to members.
  6. Click Create.
Tip: Start with Draft visibility while you build out your courses and lessons. Switch to Published when everything is ready for members.

After creation, your program appears as a card on the Courses tab. The card shows the cover image, title, description, course count, and a Draft badge if unpublished. Click the edit or delete icons on the card to update or remove the program.

Add a course to the program

  1. Click the program card to open it.
  1. Click + New course.
  2. Enter a Title and optionally a Description.
  3. Under Program, select the program to assign the course to. Select None (standalone course) to create a course that is not part of any program.
  1. Under Cover image, click Add a cover image to upload an image.
  2. Under Visibility, select Draft or Published.
  3. Optionally check Completion certificate to award members a certificate when they finish all lessons.
  4. Click Create.

The course appears inside the program. The course card shows the title, description, lesson count, and a Draft badge if unpublished.

Add lessons to a course

  1. Click the course card to open it.
  1. Click + New lesson.
  2. Under Lesson type, select one:
    • Video — upload an MP4 file or embed a YouTube/Vimeo link.
    • Text — write lesson content using the rich text editor.
  3. Enter a Title for the lesson.

The remaining fields depend on the lesson type you selected.

Add a video lesson

  1. Under Video source, select one:
    • Upload MP4 — upload a video file directly. The file is stored in secure storage.
    • Embed URL — paste an unlisted YouTube or Vimeo embed link.
  2. If you selected Upload MP4, click Choose a video file to upload your MP4.
  3. If you selected Embed URL, paste the embed link in the Embed URL field.
  4. Enter the Duration (minutes). This is used to calculate total learning hours for certificates.
  5. Optionally add a Description.
  6. Under Visibility, select Draft or Published.
  7. Click Create.
Please note: For embedded videos, the platform cannot automatically track viewing progress. Learners mark these lessons complete themselves.

Add a text lesson

  1. Under Content, write the lesson content using the rich text editor. You can format text with bold, italic, and headings, add links, images, and embedded videos.
  2. Optionally add a Description.
  3. Under Visibility, select Draft or Published.
  4. Click Create.
